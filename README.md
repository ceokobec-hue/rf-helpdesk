# RF Helpdesk — RF Generator / Matcher 이슈 대응 지식베이스

사내 전용. 고객 문의(아크·매칭 포지션·반사파·노이즈)를 받는 자리에서
부품 사양을 즉시 확인하고, 대체품을 안전하게 판정하기 위한 도구.

> ⚠️ **이 저장소는 공개(public)입니다.**
> 코드와 문서만 올라갑니다. **고객사 이슈 이력(`data/`)과 데이터시트 원본(`datasheets/`)은
> 저장소에 포함되지 않으며, 앞으로도 올리지 않습니다.**
> 실수로 올라가는 것을 막기 위해 커밋 훅을 두었으니 클론 후 반드시 켜 주십시오 (아래 참조).

## 빠른 시작

```bash
npm install          # 1회 (의존성: pdfjs-dist 하나)
git config core.hooksPath .githooks   # 1회 — 고객 데이터 유출 방지 훅 켜기
npm run sync         # 제조사 데이터 수집·대조 (최초 1회, 이후 갱신 시)
npm start            # 서버 기동 → http://localhost:7801
npm run verify       # 검증 스위트
```

포트를 바꾸려면 `PORT=8080 npm start`.

## 화면

| 경로 | 하는 일 |
|---|---|
| `/parts.html` | 부품 251개 조회 · 대체품 A/B/C 판정 |
| `/calc.html` | 포지션 위치 판정 · 회전량→용량 변화 · 전압/전류 마진 |
| `/quality.html` | 목록↔데이터시트 불일치 전수 목록 (제조사 문의용 근거) |

## 이 도구가 지키는 4가지 규칙

1. **추측한 숫자를 띄우지 않는다.** 못 읽은 항목은 빈칸 + 원문 링크.
2. **두 출처를 대조한다.** 불일치는 ⚠️ 로 표시하고, **보수적인 값**(낮은 정격·좁은 범위)을 채택한다.
3. **선형 유효구간 밖에서는 계산하지 않는다.** 숫자 대신 "데이터시트 곡선 참조"를 낸다.
4. **제조사 사양과 당사 판단을 분리한다.** 당사는 대리점·서비스 위치이므로 제조사 사양을 넘어선 단정을 하지 않는다.

## 현재 범위 (1단계 완료)

- ✅ Meiden 진공 커패시터 251모델(VVC 126 · VFC 125) 스펙 미러 + 데이터시트 PDF 250개
- ✅ 대체품 판정 (전기·기구·제어·냉각 4축)
- ✅ 계산기 4종
- ✅ 데이터 품질 리포트
- ⏳ 2단계: 이슈 지식베이스 · 사례 자동 적립 (엑셀 도착 후)
- ⏳ 3단계: 회신 문서 생성 (한/영) · 분석 대시보드
- ⏳ 4단계: 사내 서버 배포 · 로그인 · 백업

## 안전장치

공개 저장소이므로 실수 한 번이 곧 유출입니다. `.gitignore` 는 *실수로 add 하지 않으면* 막아주지만
`git add -f` 나 편집기의 강제 스테이징으로는 뚫립니다. 그 마지막 구멍을 커밋 훅으로 막았습니다.

```bash
git config core.hooksPath .githooks   # 클론 후 1회
```

이후 `data/` 나 `datasheets/` 경로, 또는 비밀키로 보이는 값이 스테이징되면 **커밋이 거부**됩니다.

## 라이선스 · 데이터 귀속

코드는 당사 사내 도구입니다. 부품 데이터는 전량 **MEIDENSHA CORPORATION 공개 자료**에서
수집한 것이며(수집 코드만 공개, 데이터 자체는 미포함), 사양의 권리는 제조사에 있습니다.
데이터시트가 필요하면 제조사 공식 페이지에서 받으십시오 — 이 저장소는 재배포하지 않습니다.
