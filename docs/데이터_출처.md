## 왜 사본을 두는가

제조사 서버는 `Access-Control-Allow-Origin` 헤더를 주지 않습니다.
브라우저가 다른 사이트의 자료를 직접 읽지 못하게 하는 보안 규칙(CORS) 때문에,
사내 화면에서 제조사 서버를 직접 부르면 차단됩니다.

그래서 **당사 서버가 미리 한 번 받아 사내에 사본을 두고**, 사내 브라우저는 그 사본을 봅니다.
부수 효과로 ① 인터넷이 끊겨도 조회가 되고 ② 매번 제조사 서버를 두드리지 않아 빠릅니다.

사본은 사내 기술지원 참조용입니다. **고객에게 데이터시트를 전달할 때는
제조사 공식 링크를 함께 안내**하십시오(각 모델 화면의 「제조사 페이지」).

## 수집 항목

목록 JSON에서: 품번 · 타입 · 시리즈 · 용량 · 전압 · 전류 · 외경
데이터시트 PDF에서 추가로:

- Peak test Voltage / RF Working Voltage
- Capacitance nominal
- **Linear Variability (pF/Turn) + 선형 유효 하한 `(C ≧ N pF)`**
- Maximum Current (@13.56 MHz)
- **Tuner Turns / Tuner Operating Torque**
- Total Length / Mounting Length / Outer Diameter / Weight
- 문서번호(예: `MQ90A40396`) · 표지 품번 · 냉각 방식(수랭 명시 여부)

굵게 표시한 항목은 **목록에는 없고 데이터시트에만** 있으며, 매처 정비 판단에 직결됩니다.

## 수집하지 않는(못하는) 것

- **주파수별 허용 전압·전류 곡선** — PDF에 그래프 이미지로만 실려 있어 수치를 읽어낼 수 없습니다.
  따라서 모든 마진 계산은 **13.56 MHz 정격 기준**이며, 다른 주파수는 데이터시트 곡선을 봐야 합니다.
- **용량–회전 곡선** — 같은 이유. 그래서 포지션(%)을 절대 용량(pF)으로 바꾸는 기능은 넣지 않았습니다.
  (근거: 가변형 125개 전부에서 `회전당 변화 × 총 회전수`가 `용량 범위`의 1.05 ~ 2.72배로,
   일치하는 모델이 0개였습니다. 저용량 구간이 비선형이기 때문입니다.)
