# 설치 · 운영 안내서

## 1. 필요한 것

- **Node.js 20 이상** — 이것 하나면 됩니다. 데이터베이스 서버나 빌드 도구는 필요 없습니다.
- 디스크 약 **100 MB** (데이터시트 PDF 250개 = 51 MB 포함)
- 수집을 돌릴 때만 인터넷 필요. **평소 조회는 인터넷 없이 동작**합니다.

> **왜 이렇게 단순한가**: 사내 서버는 한 번 올리면 몇 년을 갑니다. 빌드 도구나 프레임워크를
> 끼우면 버전이 올라갈 때마다 안 뜨는 사고가 납니다. 그래서 `node server.mjs` 한 줄로 뜨게 만들었습니다.

## 2. 설치

```bash
# 1) 파일을 서버에 복사
# 2) 의존성 설치 (pdfjs-dist 하나 — 데이터시트 PDF에서 글자를 뽑는 데 씁니다)
npm install

# 3) 제조사 데이터 수집 (최초 1회, 15~20분)
npm run sync

# 4) 검증
npm run verify

# 5) 기동
npm start
```

## 3. 사내 서버로 띄우기

```bash
PORT=7801 HOST=0.0.0.0 node server.mjs
```

- 팀원은 `http://<서버IP>:7801` 로 접속합니다.
- **IT팀에 요청할 것**: ① 포트 개방(사내망 한정) ② 서버 재부팅 시 자동 기동 등록
  ③ `data/` 폴더 일 1회 백업
- **외부(인터넷)에는 절대 열지 마십시오.** 고객사 이슈 이력은 NDA 대상입니다.

### 자동 기동 (리눅스 systemd 예시)

```ini
# /etc/systemd/system/rf-helpdesk.service
[Unit]
Description=RF Helpdesk
After=network.target

[Service]
WorkingDirectory=/opt/rf-helpdesk
ExecStart=/usr/bin/node server.mjs
Environment=PORT=7801 HOST=0.0.0.0
Restart=always
User=rfhelp

[Install]
WantedBy=multi-user.target
```

`sudo systemctl enable --now rf-helpdesk`

### 윈도우 서버

작업 스케줄러에 「시스템 시작 시」 트리거로 `node.exe server.mjs` 등록.
방화벽에서 해당 포트를 **사내망(도메인/개인 프로필)만** 허용.

## 4. 데이터 갱신

제조사가 제품을 추가하거나 데이터시트를 개정하면 다시 받아야 합니다.

```bash
npm run sync            # 새 파일만 받음 (이미 받은 PDF는 재사용)
npm run sync -- --force # 전부 다시 받음
npm run verify          # 갱신 후 반드시 검증
```

수집이 끝나면 `성공 / 추출실패 / 불일치 / 품번오류` 를 화면에 출력하고,
`data/sync-report.json` 에 남깁니다. **불일치가 늘었으면 `/quality.html` 에서 확인**하십시오.

권장 주기: **분기 1회** + 제조사 공지가 있을 때.

## 5. 백업

`data/` 폴더만 복사하면 됩니다. 파일 기반이라 서비스를 멈추지 않아도 됩니다.

```bash
tar czf rf-helpdesk-data-$(date +%Y%m%d).tar.gz data/
```

`datasheets/` 는 언제든 `npm run sync` 로 다시 받을 수 있으니 백업하지 않아도 됩니다.

## 6. 문제가 생겼을 때

| 증상 | 원인 · 조치 |
|---|---|
| 화면에 "데이터를 불러오지 못했습니다" | `npm run sync` 를 아직 안 돌렸습니다 |
| 데이터시트 PDF가 안 열림 | `datasheets/` 폴더가 비었습니다 → `npm run sync` |
| 수집 중 다운로드 실패 | 제조사 서버 일시 장애. 잠시 후 재실행 (받은 것은 재사용됩니다) |
| 포트 충돌 | `PORT=7802 npm start` |
| `npm run verify` 에서 #1 건너뜀 | `pdftotext` 가 없습니다. 맥/리눅스는 `brew install poppler` / `apt install poppler-utils` |
